주식 데이터 수집 MVP (실거래 주문 기능 없음)
1) Windows에서 Python 3.11+ 설치
2) 폴더에서 터미널 열기
3) python -m pip install -r requirements.txt
4) 국장: python collect.py kr
5) 미장: python collect.py us
6) reports 폴더의 CSV 확인

주의:
- pykrx와 yfinance는 공식 유료 시세 API가 아닌 비공식 데이터 접근 경로입니다.
- 실행 환경의 인터넷 연결이 필요하며, 차단/지연/수정 데이터가 발생할 수 있습니다.
- 장 마감일, 데이터 날짜, 종목 수, 가격의 타 공급원 대조 후에만 사용하세요.
- 국장 스크립트는 당일 단면 자료만 저장하며 20일 평균 거래량 스캔은 아직 구현되지 않았습니다.
- 미국 스크립트는 일부 지표와 종목만 수집하며 미국 전체 종목 분석이 아닙니다.
- 자동 실행, ChatGPT 보고 연동, API 키 연결은 아직 설정되지 않았습니다.
- 데이터 제공처 약관 및 상업적 사용 제한을 확인하세요.
